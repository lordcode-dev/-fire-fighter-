PHYSICAL ASSEMBLY

Where does everything go?

The robot is divided into physical zones. Keeping each zone organized makes construction easier and prevents cables, tubing and electronics from interfering with each other.

FRONT CENTER

📡 Ultrasonic Sensor

Mount the HC-SR04 at the front center of the robot. Both ultrasonic transducers should face directly forward.

Height: approximately 3–7 cm above the chassis.

Purpose: obstacle and stopping-distance measurement.

FRONT LEFT / CENTER / RIGHT

🔥 Flame Sensors

Mount three flame sensors across the front edge.

Left sensor → A0
Center sensor → A1
Right sensor → A2

Keep the three sensors facing forward and at similar heights.

FRONT CENTER

💧 Servo + Nozzle

Mount the servo behind the front nozzle. The servo horn rotates the nozzle left and right.

Keep the nozzle clear of the ultrasonic sensor and flame sensors.

CENTER LEFT

💧 Water Tank

Place the water tank toward the center-left of the chassis. This keeps the weight low and leaves the electronics side dry.

The tank should be mechanically secured so it cannot move when the robot accelerates or turns.

CENTER LEFT / BESIDE TANK

💧 Pump

Place the pump close to the tank outlet to keep the water tube short.

Route the water tube toward the front without passing above the Arduino or L298N.

CENTER / REAR

🟢 Arduino UNO

Mount the Arduino on standoffs rather than directly against the chassis.

Keep the USB connector accessible so you can reprogram the robot without removing components.

REAR RIGHT

⚙️ L298N Motor Driver

Keep the L298N close to the motor wires to reduce long motor cable runs.

Leave the screw terminals accessible for maintenance.

REAR / LOW CENTER

🔋 Battery

Mount the battery low and securely. Keep it away from the water tank outlet and pump tubing.

The battery should be removable for charging and maintenance.

DRY ELECTRONICS ZONE

🔌 Relay Module

Mount the relay in the dry electronics area. Do not position it directly below the water tank or tube.

CABLE MANAGEMENT

One robot. Four clean cable routes.

Do not allow wires to cross randomly over the robot. Use dedicated cable routes so the robot stays easy to repair.

ROUTE A

🔴 Power Route

Battery → power distribution → motor driver / approved power arrangement.

Keep high-current motor wiring away from sensitive sensor wires where practical.

ROUTE B

🔵 Motor Route

Keep motor wires along the chassis edges. Secure them so they cannot touch wheels, axles or moving parts.

ROUTE C

🟡 Sensor Route

Flame and ultrasonic wires should travel from the front sensors toward the electronics area along one controlled cable channel.

ROUTE D

🟢 Control Route

Servo, relay and other low-current control wires should follow the opposite side of the chassis where possible.

WATER SYSTEM

Keep water and electronics separated

1️⃣ Tank

Secure the water bottle/tank so it cannot move. Check the cap and outlet for leaks before mounting electronics.

2️⃣ Pump

Mount the pump beside the tank. Keep the inlet tube short and avoid sharp bends that could restrict water flow.

3️⃣ Tube

Route the tube along the side of the robot. Use clips or ties. Never let it hang over the Arduino or motor driver.

4️⃣ Nozzle

Connect the tube to the servo-controlled nozzle. Test the servo movement before operating the pump.

IMPORTANT

Things you should not do

⚠️ Electrical

  • Do not connect an unknown battery voltage directly to an Arduino pin.
  • Do not short 5V and GND.
  • Verify polarity before powering the system.
  • Check the actual specifications of your L298N, relay and pump.

💧 Water

  • Keep water away from exposed electronics.
  • Leak-test tubing before installing it above electronics.
  • Secure the tank so it cannot fall over.
  • Keep the pump wiring protected from water.

⚙️ Mechanical

  • Keep cables away from wheels.
  • Do not allow tubing to contact rotating parts.
  • Check that every component is mechanically secure.
  • Do not let the nozzle hit the sensors while rotating.

🔥 Fire Testing

  • Perform tests in a controlled environment.
  • Keep appropriate fire-safety equipment nearby.
  • Do not leave an operating flame unattended.
  • Start with low-risk tests before full operation.
SOFTWARE DEVELOPMENT

Five-stage robot development

Build and test the robot one system at a time instead of trying to debug everything simultaneously.

🚗 Stage 1 — Movement Test

First prove that the chassis, motors and motor driver work correctly. Do not install the water system until the basic drive system works.

Arduino UNO L298N 4 DC Motors 4 Wheels 4WD Chassis Battery

Arduino Code

const int ENA = 5;

const int IN1 = 7;
const int IN2 = 8;

const int IN3 = 9;
const int IN4 = 10;

void stopRobot(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,LOW);
}

void forward(){

  digitalWrite(IN1,HIGH);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,HIGH);
  digitalWrite(IN4,LOW);
}

void backward(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,HIGH);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,HIGH);
}

void setup(){

  pinMode(ENA,OUTPUT);

  pinMode(IN1,OUTPUT);
  pinMode(IN2,OUTPUT);

  pinMode(IN3,OUTPUT);
  pinMode(IN4,OUTPUT);

  analogWrite(ENA,180);

  stopRobot();
}

void loop(){

  forward();
  delay(3000);

  stopRobot();
  delay(1500);

  backward();
  delay(3000);

  stopRobot();
  delay(3000);
}

🔥 Stage 2 — Approach Fire

Add the three flame sensors and ultrasonic sensor. The robot should determine the direction of the flame and stop at the desired distance.

Flame Left → A0 Flame Center → A1 Flame Right → A2 HC-SR04 → D11/D12

Arduino Code

const int ENA = 5;

const int IN1 = 7;
const int IN2 = 8;
const int IN3 = 9;
const int IN4 = 10;

const int FLAME_LEFT = A0;
const int FLAME_CENTER = A1;
const int FLAME_RIGHT = A2;

const int TRIG = 11;
const int ECHO = 12;

const int STOP_DISTANCE = 10;

int distanceCM(){

  digitalWrite(TRIG,LOW);
  delayMicroseconds(2);

  digitalWrite(TRIG,HIGH);
  delayMicroseconds(10);

  digitalWrite(TRIG,LOW);

  long duration =
    pulseIn(ECHO,HIGH,30000);

  if(duration == 0)
    return 999;

  return duration * 0.0343 / 2;
}

void stopRobot(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,LOW);
}

void forward(){

  digitalWrite(IN1,HIGH);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,HIGH);
  digitalWrite(IN4,LOW);
}

void turnLeft(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,HIGH);

  digitalWrite(IN3,HIGH);
  digitalWrite(IN4,LOW);
}

void turnRight(){

  digitalWrite(IN1,HIGH);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,HIGH);
}

void setup(){

  pinMode(ENA,OUTPUT);

  pinMode(IN1,OUTPUT);
  pinMode(IN2,OUTPUT);

  pinMode(IN3,OUTPUT);
  pinMode(IN4,OUTPUT);

  pinMode(TRIG,OUTPUT);
  pinMode(ECHO,INPUT);

  analogWrite(ENA,170);

  stopRobot();
}

void loop(){

  int left =
    analogRead(FLAME_LEFT);

  int center =
    analogRead(FLAME_CENTER);

  int right =
    analogRead(FLAME_RIGHT);

  int distance =
    distanceCM();

  if(distance <= STOP_DISTANCE){

    stopRobot();

    while(true){}
  }

  if(center < left && center < right){

    forward();

  }else if(left < right){

    turnLeft();

  }else{

    turnRight();
  }

  delay(40);
}

💧 Stage 3 — Water Attack

Install the tank, pump, relay, tubing, servo and nozzle.

Water Tank Pump Relay Servo → D6 Relay → D4

Arduino Code

#include <Servo.h>

const int RELAY_PIN = 4;
const int SERVO_PIN = 6;

Servo nozzle;

void pumpOn(){

  /*
    Change HIGH/LOW if your relay
    is active-low instead of active-high.
  */

  digitalWrite(RELAY_PIN,LOW);
}

void pumpOff(){

  digitalWrite(RELAY_PIN,HIGH);
}

void setup(){

  pinMode(RELAY_PIN,OUTPUT);

  nozzle.attach(SERVO_PIN);

  pumpOff();

  nozzle.write(90);
}

void loop(){

  nozzle.write(60);
  delay(500);

  pumpOn();
  delay(1200);

  pumpOff();

  nozzle.write(90);
  delay(500);

  pumpOn();
  delay(1200);

  pumpOff();

  nozzle.write(120);
  delay(500);

  pumpOn();
  delay(1200);

  pumpOff();

  nozzle.write(90);

  delay(3000);
}

🔥 Stage 5 — Long Range Fire Detection

Use the three flame sensors to search for the strongest flame direction. Sensor range must be experimentally calibrated because the analog reading is not a universal distance measurement.

Left A0 Center A1 Right A2 Calibration Required

Arduino Code

const int ENA = 5;

const int IN1 = 7;
const int IN2 = 8;
const int IN3 = 9;
const int IN4 = 10;

const int FLAME_LEFT = A0;
const int FLAME_CENTER = A1;
const int FLAME_RIGHT = A2;

const int FLAME_THRESHOLD = 500;

void stopRobot(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,LOW);
}

void forward(){

  digitalWrite(IN1,HIGH);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,HIGH);
  digitalWrite(IN4,LOW);
}

void left(){

  digitalWrite(IN1,LOW);
  digitalWrite(IN2,HIGH);

  digitalWrite(IN3,HIGH);
  digitalWrite(IN4,LOW);
}

void right(){

  digitalWrite(IN1,HIGH);
  digitalWrite(IN2,LOW);

  digitalWrite(IN3,LOW);
  digitalWrite(IN4,HIGH);
}

void setup(){

  pinMode(ENA,OUTPUT);

  pinMode(IN1,OUTPUT);
  pinMode(IN2,OUTPUT);

  pinMode(IN3,OUTPUT);
  pinMode(IN4,OUTPUT);

  Serial.begin(9600);

  analogWrite(ENA,160);

  stopRobot();
}

void loop(){

  int leftValue =
    analogRead(FLAME_LEFT);

  int centerValue =
    analogRead(FLAME_CENTER);

  int rightValue =
    analogRead(FLAME_RIGHT);

  Serial.print("L: ");
  Serial.print(leftValue);

  Serial.print(" C: ");
  Serial.print(centerValue);

  Serial.print(" R: ");
  Serial.println(rightValue);

  bool flameDetected =
    leftValue < FLAME_THRESHOLD ||
    centerValue < FLAME_THRESHOLD ||
    rightValue < FLAME_THRESHOLD;

  if(!flameDetected){

    left();

    delay(250);

    stopRobot();

    delay(100);

    return;
  }

  if(centerValue <= leftValue &&
     centerValue <= rightValue){

    forward();

  }else if(leftValue < rightValue){

    left();

  }else{

    right();
  }

  delay(100);
}
