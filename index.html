Firefighter Robot

Complete offline wiring and build guide for an Arduino Uno robot using an L298N motor driver.

⚠️ IMPORTANT BEFORE BUILDING
This guide is designed for your team's planned robot. Check the labels on the actual L298N board before connecting power. L298N boards vary slightly. Never connect the motor battery directly to the Arduino 5V pin.

1 Movement

Build the basic 4-wheel robot and make it move.

🧰 Components required

🧠 Arduino Uno Main controller.
⚙️ L298N Motor driver.
🛞 4 × identical motors Two motors on each side.
🔋 Battery Motor power.
🟩 Breadboard Common-ground/control distribution.
🔌 Jumper wires Male-Male Male-Female if required
